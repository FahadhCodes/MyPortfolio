System

Developed a dynamic university management system integrating the main website with a learning management module. Implemented an Admin panel for efficient CRUD operations using the Fetch API for smooth data handling, along with separate dashboards for staff and students. Designed responsive interfaces with Bootstrap and added interactivity using JavaScript. A Library Management
System (LMS)

A Library Management System (LMS) prototype developed using C# WinForms to streamline basic library operations and user access. The system features a secure login interface with masked password input, structured UI design, and error handling for authentication. Designed with an expandable architecture, it serves as a foundation for future enhancements like database integration, CRUD operations, and role-based access. This project demonstrates core concepts in desktop application development, user interface design, and scalable system planning.

Customer Order Management
System

A Customer Order Management System developed in C to manage customer details, product orders, and billing through a menu-driven console interface. The system supports adding, updating, deleting, and searching customer records, along with dynamic product management and real-time total price calculation. It also generates detailed bills with delivery tracking and stores data using file handling. Built using linked lists and modular functions, the project demonstrates strong fundamentals in data structures, file management, and structured programming.
